만두전

⏱ 15분 · 난이도 쉬움 · 1인분

냉동만두를 계란옷 입혀 부치면 술안주로도 좋은 만두전이 된다.

// 필요한 재료

  • 만두6개(냉동)
  • 계란1개
  • 식용유1큰술

// 있으면 더 좋은 재료

  • 대파1/4대
  • 케찹1큰술

만드는 법

  1. 냉동만두 6개를 살짝 찜기나 전자레인지로 1분 데워 반쯤 해동한다.
  2. 만두를 눌러 납작하게 편다.
  3. 계란 1개를 풀어 만두에 옷을 입힌다.
  4. 팬에 식용유 1큰술을 두르고 계란옷 입힌 만두를 앞뒤로 각 2분씩 굽는다.
TIP. 케찹을 곁들이면 아이 입맛에도 잘 맞는다.
