된장찌개

⏱ 20분 · 난이도 쉬움 · 1~2인분

냉장고 야채를 정리하며 끓이는 자취생 국룰 찌개.

// 필요한 재료

  • 된장1과 1/2큰술
  • 두부1/2모(150g)
  • 애호박1/4개
  • 대파1/4대

// 있으면 더 좋은 재료

  • 감자1/2개
  • 양파1/4개
  • 청양고추1개

만드는 법

  1. 냄비에 물 400ml를 붓고 된장 1과 1/2큰술을 잘 풀어준다.
  2. 애호박 1/4개와 감자 1/2개를 나박 썰어 넣고 센 불에서 끓인다.
  3. 끓기 시작하면 중불로 줄여 5분 더 끓인다.
  4. 두부 1/2모와 대파 1/4대를 넣고 3분 더 끓여 마무리한다.
TIP. 된장은 체에 걸러 풀면 덩어리 없이 훨씬 부드러운 국물이 된다.
