계란 라면

⏱ 10분 · 난이도 매우 쉬움 · 1인분

자취방 냉장고에 계란과 파만 있으면 실패하지 않는 기본 라면.

// 필요한 재료

  • 라면1개
  • 계란1개
  • 대파1/4대

// 있으면 더 좋은 재료

  • 김치1/2컵(70g)
  • 치즈1장
  • 만두3개

만드는 법

  1. 물 550ml가 끓으면 면과 스프를 넣는다.
  2. 1분 정도 끓으면 계란 1개를 톡 깨서 넣고 젓지 않고 그대로 익힌다.
  3. 대파 1/4대를 썰어 넣고 30초 더 끓인다.
  4. 면이 익으면(총 4분) 불을 끄고 그릇에 담는다.
TIP. 계란은 노른자가 반쯤 익을 때 불을 끄면 국물과 어우러져 더 부드럽다.
