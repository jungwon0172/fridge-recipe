김치만두국

⏱ 15분 · 난이도 쉬움 · 1인분

냉동만두와 신김치의 조합, 속이 편안해지는 국물 요리.

// 필요한 재료

  • 만두8개(냉동)
  • 김치1/2컵(70g)
  • 대파1/4대
  • 간장1큰술

// 있으면 더 좋은 재료

  • 계란1개
  • 두부1/4모(75g)

만드는 법

  1. 냄비에 물 500ml를 붓고 끓인다.
  2. 김치 1/2컵을 썰어 넣고 3분 정도 끓여 신맛을 우려낸다.
  3. 냉동만두 8개를 넣고 만두가 떠오를 때까지(약 5분) 끓인다.
  4. 간장 1큰술로 간을 맞추고 대파 1/4대를 올려 마무리한다.
TIP. 계란 1개를 풀어 넣으면 국물이 더 부드러워진다.
