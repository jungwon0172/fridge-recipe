라볶이

⏱ 15분 · 난이도 쉬움 · 1인분

라면 하나로 끝내기 아쉬울 때, 떡과 어묵을 더해 라볶이로 업그레이드.

// 필요한 재료

  • 라면1개
  • 떡1컵(120g)
  • 어묵1장(50g)
  • 고추장1큰술

// 있으면 더 좋은 재료

  • 대파1/4대
  • 계란1개

만드는 법

  1. 냄비에 물 500ml와 라면 스프, 고추장 1큰술을 넣고 끓인다.
  2. 떡 1컵과 어묵 1장을 넣고 3분 끓인다.
  3. 라면 사리를 넣고 3분 더 끓인다.
  4. 대파를 올려 마무리한다.
TIP. 국물을 더 걸쭉하게 하고 싶으면 물을 100ml 줄여서 끓인다.
