오징어볶음

⏱ 20분 · 난이도 보통 · 2인분

손질된 냉동 오징어로 간단하게 만드는 매콤한 술안주 겸 반찬.

// 필요한 재료

  • 오징어1마리(손질됨, 250g)
  • 고추장1과 1/2큰술
  • 양파1/2개
  • 대파1/4대

// 있으면 더 좋은 재료

  • 당근1/8개
  • 청양고추1개

만드는 법

  1. 오징어 1마리는 몸통에 칼집을 내고 한입 크기로 썬다.
  2. 고추장 1과 1/2큰술, 간장 1큰술, 설탕 1큰술로 양념장을 만든다.
  3. 팬에 식용유 1큰술을 두르고 양파 1/2개를 1분 볶는다.
  4. 오징어와 양념장을 넣고 센 불에서 4분 볶은 뒤 대파를 올려 마무리한다.
TIP. 오징어를 너무 오래 볶으면 질겨지니 센 불에서 짧게 볶는다.
